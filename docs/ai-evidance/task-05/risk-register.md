## Scoring
- Likelihood (L): 1 = unlikely, 2 = possible, 3 = already happening / very likely
- Impact (I): 1 = cosmetic, 2 = degrades quality or slows development, 3 = wrong data, security breach or broken app
- Score = L × I (1–9). Only Confirmed risks are scored and ranked.
- Ranking: by score, then by impact (higher first), then by cost of the fix (cheaper first).
