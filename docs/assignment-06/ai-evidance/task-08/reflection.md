In this assignment I used Claude Code (Claude Opus 5.5) to specify, build and review a budget check for my Expense Tracker, and I rebuilt the same feature in Appsmith. The agent was most useful for speed and for producing evidence: it wrote the backend endpoint, the React card and 31 tests, and it ran every test case in a real browser with screenshots. However, its first version was not correct. The separate AI review found that a limit smaller than one cent gave a wrong status and that the budget card showed old numbers after I added an expense. I confirmed both with curl and with tests that failed before the fix. Not every finding held up: the reviewer claimed that the repository had no remote, which was false, and a race condition it described could not be reproduced because the button blocks repeated submits. One finding was really a design decision, not a defect. My main lesson is that AI output is a hypothesis until a command, a test or a screenshot proves it. The mutation check showed that the new tests really protect the fixes.
